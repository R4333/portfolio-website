For Levitate Data

An enterprise RAG platform. Tenants upload large document sets and ask questions in plain English; Thalamus runs hybrid vector search with re-ranking and answers with citations. Deloitte Internal RAG

For Deloitte

Search and chat for Deloitte consultants, across the knowledge silos they already use: SharePoint, Confluence, Azure files and ServiceNow. An ingestion pipeline chunks and embeds documents into Azure AI Search; answers come from Azure OpenAI, grounded with citations, and Entra ID decides what each person is allowed to see. Deployed serverless on Azure Container Apps, with the whole stack defined as Bicep.
